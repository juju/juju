# `jujuagentd`

In Juju, `jujuagentd` is the executable binary that implements {ref}`agent <agent>` functionality for the entities in a Juju deployment on a machine cloud (model, machine, unit, controller) and for some of the entities in a Juju deployment on a Kubernetes cloud (model, controller). On a Kubernetes cloud, unit agents run {ref}`containeragent`.

Earlier Juju releases named this binary `jujud`. Agent binary archives still include a small `jujud` shell shim that forwards to `jujuagentd`, so that init scripts generated by earlier versions keep working.
